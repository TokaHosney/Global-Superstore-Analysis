# 📊 Global Superstore Analysis 

An end-to-end Power BI project developed as part of a training program, analyzing sales performance, profit trends, return rates, and category contribution using Excel, Power Query, and DAX to build an interactive dashboard.

## 🔧 Tools Used
Power BI | Excel | Power Query | DAX

## 📌 Project Highlights
- Interactive dashboard for business performance analysis  
- KPI tracking (Sales, Profit, Return Rate)  
- Data modeling with relational structure  
- Advanced DAX measures for insights
